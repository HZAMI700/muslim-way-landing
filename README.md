# طريق المسلم — Muslim Way Landing Page

صفحة هبوط عربية متكاملة لتطبيق **طريق المسلم (Muslim Way)** على متجر Google Play.

🔗 **رابط التحميل المباشر على Google Play:**  
https://play.google.com/store/apps/details?id=com.muslimway.iman&hl=ar

## المميزات المعروضة في الصفحة
- أيقونة التطبيق الرسمية ولقطات الشاشة الحقيقية من Google Play.
- زر تحميل مباشر يوجّه المستخدم إلى صفحة التطبيق على Google Play.
- عرض شامل لجميع مميزات التطبيق الـ12: القرآن الكريم كاملاً، مواقيت الصلاة الدقيقة، بوصلة القبلة، مكتبة الحديث (+7,500 حديث)، الأدعية والأذكار (+120 تصنيف)، المسبحة الرقمية، الاختبار الإسلامي، تلاوات القرآن الكريم، أسماء الله الحسنى الـ99، التقويم الهجري، الإشعارات الذكية، والتصميم العصري.
- دعم كامل لاتجاه الكتابة من اليمين إلى اليسار (RTL) مع وضع داكن وفاتح (Dark / Light Mode) ومتجاوب مع جميع الشاشات.

## التشغيل محليًا
افتح الملف `index.html` مباشرة في المتصفح أو شغّل خادمًا محليًا:

```bash
python -m http.server 8080
```
